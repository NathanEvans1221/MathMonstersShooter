# 遊戲優化 Issue 批次執行計畫

> 執行方式：superpowers:executing-plans，逐項測試、commit、push、確認遠端後關閉 Issue。

## 目標與設計
保留 Vue 3 與 Canvas 架構，改善低年級使用者的可靠性、操作與學習回饋。
使用 Node 內建測試，不引入狀態管理框架。既有 main 為使用者指定交付的目前分支，
依本輪明確授權在目前乾淨 checkout 逐項提交，不另建立工作樹。

## 規則決定
- 難度：簡單／中等／困難通關 250／350／400 分。
- 加法最大運算元 5／9／9；減法答案與減數上限 5／9／9；乘法上限 5／9／9。
- 初速 0.35／0.5／0.65，擊殺加速係數 0.06／0.08／0.1。
- 答錯不扣命，減速五秒；漏怪扣命。升級喘息從 100 分整數門檻開始。
- 十題練習一次一題：首次答案決定首次正確率，答錯可繼續；擊殺或漏怪算完成。
  練習不因三次漏怪提早結束；漏題與曾答錯題列入複習，不寫入射擊最高分。
- 同題連錯兩次提示；切換目標或答對清除提示，提示不直接顯示最終答案。
- 語音：勝敗可搶占；數字不被普通回饋打斷，僅保留最新一筆待播內容。
- 返回前景不自動恢復；儲存不可用時以記憶體預設繼續運作。
