# 效能驗證：減少重複工作（#8）

日期：2026-10-23。使用本機 Edge 無頭、600×900 畫面、五隻固定怪物，
字型載入後同步執行 update(0) 與 draw，共七輪、每輪 1,000 次。
腳本：scripts/benchmark.cjs；優化前程式提交為 62f3b52。

| 項目 | 優化前 | 優化後 |
|---|---:|---:|
| 選項通知次數 | 7,000 | 1 |
| measureText 次數 | 42,000 | 5 |
| 每幀 CPU 時間中位數 | 0.0423 ms | 0.0433 ms |

原始資料保存在 performance-before.json 與 performance-after.json。
通知與文字測量明確減少；CPU 時間沒有明顯改善，約 0.001 ms 差異不足以推論速度提升。
此量測是同步微型場景，沒有代表螢幕刷新率、完整 GPU 合成、手機效能或真實 FPS。

快取以字型與算式為鍵，在新局、視窗縮放、字型完成載入時清除。
單元測試另外涵蓋無目標只清空一次、縮放及字型失效；完整瀏覽器流程仍正常。
